# Project history and attribution

## Original CS 360 work

The original 2025 coursework by Michael Wood defined the weight-tracking problem, target users, navigation concepts, account and goal requirements, UI wireframes, and an Android Studio prototype. That prototype included early login, dashboard, entry, edit, and settings layouts.

## Portfolio modernization

The version in this repository was rebuilt after the course submission. The modernization:

- replaced a fixed demonstration login with local account creation and salted password hashing;
- implemented a normalized SQLite schema and per-account record isolation;
- completed add, edit, delete, goal, settings, session, and notification behavior;
- corrected activity declarations and navigation;
- replaced fixed-position classroom layouts with responsive Material screens;
- lowered the minimum Android version from API 34 to API 26;
- added unit tests, CI, architecture notes, privacy controls, and portfolio documentation.

The original assignment documents and screenshots are not published because they contain academic identity details and do not represent the finished application. This repository presents the resulting software and explains the evolution without claiming that post-course enhancements were part of the graded submission.
